# Learning Python 
Personal repository for learning scientific Python, with a focus on aerospace 
engineering applications. Maintained by an Aerospace Engineering student at FH Aachen(4th semester)
## Stack 
-Python 3.14.4
-Numpy, SciPy, Pandas,Matplotlib
-Managed with [uv](https://git@github.com/astral-sh/uv)
## Setup
```bash
git clone git@github.com:takamw12-cell/learning-python.git
cd learning-python
